1

Image Acquisition & Preprocessing

Goal: Capture clear images of labels that work for OCR.

Common Problems

  • Small fonts, poor contrast, glare on glossy packaging
  • Curved or tilted labels (e.g., bottles, cans)
  • Motion blur and poor lighting conditions

Techniques Used

  • Image enhancement (histogram equalization, denoising)
  • Perspective correction using homography matrices
  • Bounding box detection for text regions
Perspective Correction:
[x', y', 1]T = H[x, y, 1]T
Where H is the homography matrix transforming I(x,y) → I'(x',y')

OCR Methods for Food Labels

Goal: Convert label text into machine-readable content.

Traditional OCR

Tools: Tesseract

✅ Strengths
  • Fast processing
  • Lightweight
  • Good for clean text
⚠️ Weaknesses
  • Fails with irregular fonts
  • Poor on noisy layouts
  • Limited curved text support

Deep Learning OCR

CRNN (Convolutional Recurrent Neural Network): Extracts image features with CNN, sequences with RNN.

yt = Softmax(Wht + b)
Where ht is RNN hidden state at time t

Other Methods:

  • YOLO + OCR: Detects text regions quickly before recognition
  • Transformer-based OCR: Uses self-attention for multi-language, curved text

Specialized Recognition Tasks

Goal: Extract meaningful information (not just raw text).
🥗

Nutritional Labels

Extract structured values (calories, sugar, fat) from nutrition facts panels.

Research: Saputra et al. (2024) showed bounding box segmentation increased accuracy [1].

📅

Expiration Dates

Problem: Many formats ("Best by 06/25", "06/2025", etc.)

Solution: Grumeza et al. (2024) combined EasyOCR + LLMs to interpret ambiguous formats [2].

⚠️

Allergen Detection

Johan & Rizal (2021): Used OCR + Boyer-Moore string matching against allergen keywords (milk, soy, nuts, etc.) [5].

⚠️ Limitation: Works only if OCR accuracy is high.
